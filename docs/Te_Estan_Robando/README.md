# TE ESTÁN ROBANDO — El barrio no duerme

**Paquete de especificación y validación para Hack The Andes 2026.**

Este ZIP contiene documentos Markdown separados para mantener **trazabilidad de problema, solución, UX, escenarios, arquitectura, evaluación y pitch**. Los archivos originales se incluyen sin editar.

**Comienza en [INDICE.md](INDICE.md).**

## Advertencia de alcance
El videojuego es un laboratorio con transacciones ficticias. No opera sobre bancos reales ni demuestra por sí mismo impacto productivo. El repositorio de la solución no fue inspeccionado; contratos y estados nuevos deben cotejarse con código. La pausa y evaluación pueden ser automáticas, pero la versión documentada del equipo requiere intervención humana para confirmar durablemente una cuenta como mula. Para mostrar autonomía completa en juego: fixture confirmado previamente o sospecha provisional con TTL, sin confundirlos.

## Entrega
Documentos funcionales y de diseño: `docs/`. Diez fichas reproducibles: `escenarios/`. Material anterior: `originales/`. Formatos de pruebas y eventos: `plantillas/`. El manifiesto SHA-256 permite cotejar archivos.

## Verificación clave
El valor diferencial se prueba si se ejecuta una transferencia simulada **y queda retenida en ledger antes de invocar IA**, si una cuenta confirmada se identifica en una siguiente operación sin repetir investigación, y si un pago legítimo puede pasar. Nunca maquillar fallos ni cifras.

# Checklist de demo pública / jurado

- [ ] URLs de app, slides y repo funcionan en incógnito desde otra red.
- [ ] La app no necesita sesión personal del equipo.
- [ ] Simulación marcada en pantallas.
- [ ] Al crear run, aparecen `run_id` y versión del escenario.
- [ ] S01 mantiene `HELD` antes de cualquier llamada IA.
- [ ] `HELD` no se convierte en `RELEASED` sin Policy legítima.
- [ ] S03 Memoria sólo para veredicto confirmado o seed etiquetada.
- [ ] S04 permite pago legítimo o registra FP explícito.
- [ ] Event stream y DB coinciden, con reconnect.
- [ ] Métricas del monitor tienen `n` y no muestran números de maqueta.
- [ ] El presentador puede ejecutar en 90 s con un navegador.
- [ ] Las fallas son visibles y existe replay etiquetado como tal.
- [ ] El README de entrega declara restricciones reales.
- [ ] Secretos y PII están fuera de repo y logs.
